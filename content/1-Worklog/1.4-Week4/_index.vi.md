### Kết quả đạt được tuần 4

* Hiểu kiến trúc và các thành phần của Amazon VPC.

* Nắm được chức năng của:
  * Internet Gateway
  * NAT Gateway
  * Route Table
  * Subnet
  * Network ACL
  * Security Group

* Tạo thành công:
  * VPC tùy chỉnh
  * Public Subnet
  * Private Subnet

* Cấu hình Route Table và liên kết đúng với từng Subnet.

* Hiểu sự khác nhau giữa Public Subnet và Private Subnet.

* Triển khai thành công EC2 trong các Subnet khác nhau.

* Kiểm tra kết nối Internet thông qua Internet Gateway.

* Cấu hình NAT Gateway để EC2 trong Private Subnet có thể truy cập Internet phục vụ cập nhật hệ thống.

* Hiểu luồng truyền dữ liệu trong mạng Amazon VPC.

* Hoàn thành toàn bộ các bài Lab về Amazon VPC và EC2 Networking.
