### Week 5 Objectives

* Master the core concepts of Amazon VPC.
* Understand Elastic IP and Route Table management.
* Learn VPC networking components.
* Practice deploying a secure VPC environment.
* Complete Amazon VPC hands-on labs.

### Tasks to be carried out this week

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | --------------- | ----------------------------------------- |
| 2 | - Review Amazon VPC architecture.<br>- Learn VPC components including VPC, Subnet, Route Table, Internet Gateway and NAT Gateway.<br>- Understand VPC design best practices. | 15/05 | 15/05 | https://000003.awsstudygroup.com/1-introduce/ |
| 3 | - Learn about Elastic IP.<br>- Associate and disassociate Elastic IP with EC2 instances.<br>- Review Route Table configuration and routing behavior.<br>- Understand public and private routing. | 16/05 | 16/05 | https://000003.awsstudygroup.com/2-firewallinvpc/2.1-securitygroup/ |
| 4 | - Practice creating a custom VPC.<br>- Create multiple Public and Private Subnets.<br>- Configure Internet Gateway, Route Tables and Security Groups.<br>- Verify network connectivity between resources. | 17/05 | 17/05 | https://000003.awsstudygroup.com/3-prerequisite/3.1-createvpc/ |
| 5 | - Practice deploying EC2 instances into different Subnets.<br>- Configure Elastic IP for a public EC2 instance.<br>- Test Internet access from Public and Private Subnets.<br>- Troubleshoot routing issues. | 18/05 | 18/05 | https://000019.awsstudygroup.com/5-routetables/ |
| 6 | - Complete Amazon VPC practice labs.<br>- Review networking architecture and routing configuration.<br>- Summarize weekly learning results and document the deployment process. | 19/05 | 19/05 |  |

### Week 5 Achievements

* Understood the architecture and design principles of Amazon VPC.

* Successfully configured:
  * Custom VPC
  * Public Subnet
  * Private Subnet
  * Internet Gateway
  * Route Table
  * Security Groups

* Learned how Elastic IP provides a static public IPv4 address for EC2 instances.

* Successfully associated and released Elastic IP addresses.

* Understood the relationship between Route Tables and Subnets.

* Deployed EC2 instances within a custom VPC architecture.

* Verified connectivity between network resources and Internet access.

* Improved understanding of AWS networking and secure resource deployment.

* Completed all Amazon VPC networking practice labs.---
