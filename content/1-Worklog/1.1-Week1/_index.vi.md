### Kết quả đạt được tuần 1

* Hiểu mục tiêu và lộ trình đào tạo của First Cloud AI Journey.

* Nắm được các kiến thức cơ bản về Cloud Computing:
  * Public Cloud
  * Private Cloud
  * Hybrid Cloud
  * Multi Cloud
  * IaaS
  * PaaS
  * SaaS

* Hiểu kiến trúc hạ tầng toàn cầu của AWS:
  * Region
  * Availability Zone
  * Edge Location

* Tạo thành công tài khoản AWS Free Tier.

* Hiểu các nguyên tắc bảo mật tài khoản AWS.

* Thực hành và cấu hình thành công IAM:
  * IAM User
  * User Group
  * IAM Policy
  * MFA
  * Password Policy

* Làm quen với AWS Management Console và cách tìm kiếm dịch vụ.

* Hiểu chức năng của các dịch vụ AWS cơ bản:
  * EC2
  * S3
  * VPC
  * IAM
  * RDS
  * CloudWatch

* Có khả năng sử dụng IAM thay cho Root User để quản lý tài nguyên AWS an toàn.

* Hoàn thành toàn bộ các bài Lab khởi động của tuần 1.
