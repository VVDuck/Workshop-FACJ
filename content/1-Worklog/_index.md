Throughout the **12-week First Cloud Journey Bootcamp - 2026** internship program, I recorded my weekly learning progress, practical exercises, project development activities, and technical achievements. The worklog reflects the knowledge acquired, hands-on AWS labs completed, and project implementation milestones from the beginning of the internship until the final report.

The program was completed over **12 weeks**, progressing from learning AWS fundamentals to designing, deploying, and completing a cloud-based project on Amazon Web Services (AWS). Each week focused on a specific learning objective and practical activities, helping strengthen both cloud computing knowledge and hands-on skills.

The weekly worklog is organized as follows:

**Week 4:** [Amazon RDS, Database Services, Backup & Restore, RDS Deployment Labs](1.4-week4/)

**Week 5:** [AWS Auto Scaling, Elastic Load Balancer (ELB), High Availability and Scalability](1.5-week5/)

**Week 6:** [Amazon S3, Storage Classes, Storage Gateway, File Gateway and S3 Practice Labs](1.6-week6/)

**Week 7:** [Review EC2 & S3, AWS Security Fundamentals, IAM, Security Best Practices and Review Labs](1.7-week7/)

**Week 8:** [AWS Workshop, Project Proposal, Solution Architecture Design and Documentation](1.8-week8/)

**Week 9:** [Project Planning, AWS Architecture Design, Service Selection and Deployment Planning](1.9-week9/)

**Week 10:** [Project Development, AWS Resource Deployment, Application Integration and Functional Testing](1.10-week10/)

**Week 11:** [Project Completion, Production Deployment, System Optimization and Documentation](1.11-week11/)
